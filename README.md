# Apex Global International School - Management System

A comprehensive, fully responsive school management portal built using modern web technologies. This project features dedicated role-based portals for Students, Parents, Teachers, and Administrators, complete with local state synchronization.

## 🌟 Key Features

- **3D Particle Engine**: Dynamic interactive canvas background that responds smoothly to mouse movements.
- **Role-Based Portals**: Tailored dashboards and features for:
  - **Students**: View daily attendance status and homework assignments.
  - **Parents**: Monitor child progress and submit support/complaint tickets.
  - **Teachers**: Manage student attendance statuses (Present/Absent/Late) and publish daily homework feeds.
  - **Administrators**: Track system users and overall school metrics.
- **Urgent Notice Popup**: Interactive school trip notification powered by a built-in web audio notification alert.
- **Local State Sync**: Seamless real-time data updates using Browser LocalStorage.

## 🛠️ Technology Stack

- **HTML5**: Structured semantic markup.
- **Tailwind CSS**: Modern utility-first styling and glassmorphism UI components.
- **JavaScript (ES6+)**: Interactive canvas mechanics, DOM manipulation, and state management.
